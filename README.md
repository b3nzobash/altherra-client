# Altherra Client

Клієнтський мод для Minecraft-сервера [Altherra](https://altherra.com.ua) (Fabric, Minecraft 26.3).
Лаунчер Altherra ставить його сам; якщо граєш через інший лаунчер — поклади jar у теку `mods`
(або завантаж усю збірку одним архівом на [altherra.com.ua/mods](https://altherra.com.ua/mods)).

## Що робить

- **Перевірка збірки.** Під час входу відповідає серверу списком своїх модів (id, версія, назва файлу, SHA-1),
  щоб сервер пускав лише з тією самою збіркою, що й у лаунчері.
- **Вхід через Discord.** Після того як ти один раз підтвердив вхід кодом у Discord, сервер видає одноразовий ключ;
  мод зберігає його в `altherra/login-keys.json` у теці гри й надсилає наступного разу — без кодів.
  Ключ іде лише на той сервер, від якого отриманий.
- **Перепідключення.** Після вильоту з сервера показує відлік і сам заходить знову; є кнопки «Підключитися зараз» і «Скасувати».
- **Нові моди.** Якщо збірку оновили, кнопка на сервері перезапускає гру через лаунчер, щоб він поставив нові моди.
- **«Вийти з гри»** замість «Відʼєднатися» в меню паузи.

Мод не збирає жодних інших даних і не звертається нікуди, крім сервера, до якого ти підключаєшся.

## Збірка

Потрібна Java 25.

```sh
./gradlew build
```

Готовий файл — `build/libs/altherra-client-<версія>.jar`.
